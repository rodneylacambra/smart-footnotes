A powerful and modern WordPress footnotes plugin with tooltip footnotes, inline expandable notes, duplicate footnote detection, custom numbering styles, and customizable themes.

== Description ==

Smart Footnotes is a modern and lightweight WordPress footnotes plugin designed for bloggers, educators, researchers, publishers, documentation websites, and content creators who want clean, elegant, and user-friendly footnotes.

Easily add footnotes, references, citations, annotations, and endnotes anywhere in your content using the shortcode [sfn]Your footnote text here[/sfn].

Unlike traditional footnote plugins, Smart Footnotes includes multiple display styles including tooltip footnotes, inline expandable notes, side panel references, and classic bottom-of-page footnotes — giving you full flexibility over how your notes appear to visitors.

Perfect for:

* Academic websites and research articles
* Blog posts with references and citations
* Documentation and knowledge bases
* Historical and educational websites
* Long-form content and storytelling
* Theology, philosophy, and scholarly writing
* Magazine and editorial content

== Installation ==

1. Upload the `smart-footnotes` folder to the `/wp-content/plugins/` directory, or install directly through the WordPress Plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to **Settings → Smart Footnotes** to configure the plugin.
4. Add footnotes using the shortcode inside posts or pages.

== Usage ==

= Basic Shortcode =

`[sfn]Your footnote text here[/sfn]`

= Example with Options =

`[sfn mode="tooltip" numbering="roman"]Your note[/sfn]`

== Available Display Modes ==

* `classic` — traditional bottom footnotes
* `tooltip` — hover tooltip footnotes
* `inline` — expandable inline notes
* `sidepanel` — side panel references

== Available Numbering Styles ==

* `numeric`
* `roman`
* `alpha`
* `symbol`

== Frequently Asked Questions ==

= How do I create a footnote? =

Simply add the shortcode inside your content:

`[sfn]Your footnote text here[/sfn]`

You can also customize the display mode and numbering style:

`[sfn mode="tooltip" numbering="roman"]Your note[/sfn]`

= Where do the footnotes appear? =

In Classic mode, footnotes appear as a numbered list at the bottom of the post with convenient back-links to the inline markers.

= Can I use tooltip footnotes? =

Yes. Smart Footnotes includes a built-in tooltip mode that displays notes when users hover or tap the footnote marker.

= Can I customize the design? =

Yes. You can customize colors, fonts, spacing, borders, alignment, themes, labels, and display styles directly from the plugin settings.

= Does it work with page builders? =

Yes. The `[sfn]` shortcode works with Elementor, Divi, WPBakery, Classic Editor, Block Editor, and most WordPress themes.

= Is it mobile friendly? =

Yes. Smart Footnotes is responsive and optimized for mobile devices.

= Can I override settings per post? =

Yes. Each post includes a Smart Footnotes sidebar settings box for per-post customization.
